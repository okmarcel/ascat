# Sample data

Run from the repository root, after creating the schema in an empty database:

```sh
docker compose exec -T postgres \
  psql -X -v ON_ERROR_STOP=1 -U ascat -d ascat \
  < database/seeds/01_sample_data.sql
```

The command uses the default database/user names; adjust them for a custom setup.
The seed is loaded manually, not automatically by Docker initialization.
It runs in one transaction and refuses nonempty application tables without
changing existing data. Use another empty database to repeat the demonstration.
IDs are generated by identity sequences; no particular numeric IDs are assumed.

| Table | Final rows |
| --- | ---: |
| users | 5 |
| samples | 8 |
| tags | 8 |
| sample_tags | 14 |
| collections | 5 |
| collection_samples | 9 |
| ratings | 8 |
| downloads | 9 |
| login_events | 7 |

Fixtures include:

- One administrator, three active regular users and one inactive regular user.
  Nina has no uploads, collections, ratings or activity.
- Seven active samples and one soft-deleted sample; all four formats, BPM 50
  and 300, unknown BPM, microsecond duration precision and repeated sample names.
- N:M memberships, collections containing other users' samples, an empty
  collection, an unused tag and a tag assigned only to the soft-deleted sample.
- Room Ambience has no tags, collections, ratings or downloads.
- Warehouse Loop has three ratings (5, 4, 2) and two downloads by the same user.
  Its report should show two downloads and three ratings, not six of each.
- Archived Bass retains tags, collection memberships, a rating and two downloads
  after soft deletion. Its owner is subsequently deactivated.
- A temporary sample is soft-deleted and then permanently deleted, leaving two
  download events with sample_id = NULL. Identity sequences retain the consumed ID.

All timestamps are fixed and include UTC offsets. Accounts use example.test
addresses and valid encoded Argon2id hashes of random, discarded passwords;
there are no known demo login credentials. Audio files are not included:
storage_key values are database fixtures, not downloadable assets.

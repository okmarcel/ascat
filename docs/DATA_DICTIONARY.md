# Data Dictionary

Schema: [00_create_schema.sql](../database/migrations/00_create_schema.sql).
PK = primary key, FK = foreign key, UK = unique key. All columns are NOT NULL
unless marked nullable. Identity keys use GENERATED BY DEFAULT AS IDENTITY.

## Domains and comparison

- BPM: integer 50–300 inclusive; NULL means unknown or not applicable.
- Ratings: integer 1–5 inclusive, displayed as stars; no half-star values.
- Formats: lowercase wav, mp3, flac or ogg, without a leading dot.
  Actual file content validation belongs to the upload service.
- Duration: numeric(12,6) seconds, positive and finite, up to 999999.999999.
  PostgreSQL rounds input to six fractional digits.
- Sample and collection names are nonblank and may repeat. Comparisons use
  ordinary PostgreSQL text semantics; case-insensitive name search uses lower(name).
- Usernames contain no whitespace; usernames and emails are unique under lower().
  Email CHECK validates basic address structure, not deliverability.
- Tag names are nonblank, have no leading/trailing ordinary spaces and are
  unique under lower(). Text case may be preserved for display.
- All three event dates use timestamptz and default to CURRENT_TIMESTAMP;
  infinite dates are rejected. Use UTC database/API sessions and explicit
  offsets for input; display in Europe/Warsaw or the user's chosen zone.
  timestamptz stores an instant, not the original named time zone.
- No created_at/updated_at columns are added: upload_date and event dates
  cover the required history; account creation and metadata edits are not audited.

## Foreign keys and indexes

All FKs use immediate, nondeferrable validation. The model has no insertion
cycles requiring deferred checks. FK actions are defined above; default ON UPDATE
NO ACTION applies. All constraint and index names are explicit in the schema.

PK/UK indexes already cover identity lookups, membership pairs and ratings by
user/sample. Case-insensitive UKs are implemented as unique expression indexes.
Additional indexes serve these operations:

| Index | Purpose |
| --- | --- |
| samples_active_name_idx | Active catalog: lower(name) prefix search using LIKE 'prefix%'. Contains searches using '%text%' may scan; no trigram extension is required at this stage. |
| samples_active_bpm_idx | Active catalog: BPM equality/range filters. |
| samples_active_upload_date_idx | Active catalog: date ranges and newest first. |
| samples_owner_upload_date_idx | Samples by owner/date; FK lookup, including soft-deleted samples. |
| collections_owner_idx | Owner's collections; owner FK lookup. |
| sample_tags_tag_sample_idx | Samples by tag; tag FK lookup. |
| collection_samples_sample_collection_idx | Collections containing a sample; sample FK lookup. |
| ratings_sample_idx | Ratings per sample and sample FK lookup. |
| downloads_user_date_idx | User download history, newest first; user FK lookup. |
| downloads_sample_date_idx | Sample popularity/history; sample FK lookup. |
| login_events_user_date_idx | Login history and last login per user; user FK lookup. |

These are initial indexes for the planned queries; performance measurements
and any changes based on EXPLAIN belong to a later step.
